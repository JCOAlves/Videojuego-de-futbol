# Videojuego-de-futbol
Vídeogame sobre Futebol criado em *Python* com a biblioteca *Pygame*.
O jogo foi criado para ser demonstrado na Mostra de Cultura Espanica no IFRN campus Parnamirim.

## Como exercuta-lo localmente na sua máquina
**Requisitos**: é necessário a linguagem Python e o gerenciador de pacotes NPM já instalados no seu PC.

1. Clone o repositório do projeto no GitHub:
```bash
git clone https://github.com/JCOAlves/Videojuego-de-futbol.git
```
2. Exercute o comando NPM a seguir para criar o ambiente virtual Python com as dependencias do projeto:
```bash
npm run venv
```
3. Por fim, inicialize o jogo com o comando:
```bash
npm run start
```
